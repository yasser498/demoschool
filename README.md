# جِسر JISR — Demo

## تشغيل التجربة
1. استورد `n8n/JISR_Demo_n8n.json` إلى n8n.
2. Save ثم Activate.
3. ارفع بقية المشروع إلى Vercel.
4. افتح الموقع.

## الحسابات
- ولي الأمر: `P1001`
- الطالب: `S1001`
- المدرسة: `ADMIN1448`

## أفضل سيناريو
1. ادخل ولي الأمر `P1001`.
2. أرسل طلب استئذان.
3. اخرج وادخل المدرسة `ADMIN1448`.
4. افتح الطلب واعتمده مع ملاحظة.
5. ارجع إلى ولي الأمر.
6. سترى الطلب مقبولًا، ورد المدرسة، والحدث داخل «صندوق ابني».

## الطالب
ادخل `S1001` لمشاهدة الجدول ونبض اليوم والإشعارات.

## Webhook
`https://n8n.yasergrid.online/webhook/jisr-demo-v1`

إذا كان دومين n8n مختلفًا عدل `assets/config.js`.

## التخزين
Demo مستقل يستخدم Workflow Static Data ولا يحتاج قاعدة بيانات.
